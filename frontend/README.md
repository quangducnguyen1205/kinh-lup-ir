# Frontend — giao diện tìm kiếm

**Người phụ trách setup:** Chính  
**Task khởi đầu:** T03 — Search UI baseline

Công nghệ: React + Vite.

## Trách nhiệm

Frontend chỉ gọi Backend API theo tab `API CONTRACT` trong Google Sheet và **không kết nối trực tiếp PostgreSQL**.

Trong lúc backend chưa hoàn thành, frontend dùng mock response đúng contract để có thể phát triển độc lập.

## Skeleton hiện có

Step 5 mới cung cấp:

- project React/Vite chạy được;
- trang placeholder để kiểm tra môi trường;
- biến `VITE_API_BASE_URL`.

Search box, result list, pagination và document detail vẫn thuộc T03.
